# SMCs HPC Toolkit

A collection of scripts and tools for system management, diagnostics, and tuning in HPC environments. Initial focus: RoCE v2 detection and tuning for RHEL Linux servers.

## Contents
- scripts/ : All diagnostic and management scripts
- .github/ : Project automation and Copilot instructions

## Usage
Scripts are designed to be run as root on RHEL-based systems. See each script for details.
